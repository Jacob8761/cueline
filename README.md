# Cueline

A teleprompter for filming YouTube videos, in a single web page.

- Paste a script, set the reading speed in words per minute, and scroll it full screen with an eye line and countdown.
- See yourself on screen while you read and record takes with your camera.
- Save takes to your Downloads folder, or (in Chrome and Edge) choose a folder to save every take automatically.

Everything stays in your browser. Scripts, settings and videos are never uploaded.

**Use it:** https://jacob8761.github.io/cueline/
